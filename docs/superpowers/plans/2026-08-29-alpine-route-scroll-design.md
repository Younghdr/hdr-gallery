# 德法瑞逐站路線動畫設計

## 目標

將德法瑞旅程頁目前的 Leaflet 路線地圖替換成網站內嵌的 D3 + Remotion + GSAP 逐站動畫。訪客不需要按播放；在路線畫面中每次有效滾輪操作只前進或後退一站，亦可使用明確的上一站、下一站與跳過路線控制。

## 使用者體驗

- 路線共 13 個主要站點，順序沿用 `components/alpine-route-map.tsx` 的城市級座標與既有繁中行程文案。
- 桌面版在指標位於路線畫面上時，以滾輪閾值與轉場鎖定確保一次只移動一站。
- 第一站向上滾時不攔截頁面；完成路線後向下滾也不攔截，避免形成捲動陷阱。
- 上一站與下一站按鈕永遠提供等價操作；下一站按鈕直接顯示下一個繁中站名。
- 「跳過路線」會完成收束動畫，然後捲動至 `#latest` 章節。
- 手機版提供按鈕與單次垂直滑動；可攔截的方向才阻止頁面捲動。
- `prefers-reduced-motion` 啟用時取消補間，直接切換站點與章節。

## 視覺

- D3 使用 `world-atlas/countries-50m.json` 與 `topojson-client` 投影德國、法國、瑞士真實國界。
- 瑞士採冰川藍低飽和填色，德法使用深灰綠；路線以橘紅色在深色軌道 halo 上逐段顯示。
- 左下資訊區顯示站號、國家代碼、英文站名、繁中站名與既有行程說明。
- 頂部保留 `EXPEDITION 22`、三國英文與 `12 DAYS · 13 STOPS`；右上提供跳過路線。
- 桌面構圖為 16:9；手機維持可讀文字、按鈕與完整路線，不以放大標題填滿畫面。

## 技術責任

- D3：投影國界、站點與 SVG 路徑幾何。
- Remotion Player：提供無控制列的確定性影格播放頭；網站只透過 `seekTo()` 移動影格。
- GSAP：在 composition 內以 `useGsapTimeline()` 編排站點資訊的進出，不自行播放 timeline。
- React：管理目前站點、滾輪／觸控意圖、跳過與章節導覽。

## 時間模型

- 影片規格固定為 1920×1080、30 fps。
- 每兩個站點目標影格相隔 24 frames；最後另有 24 frames 完成回到法蘭克福的閉合線段。
- 網站轉場以約 720ms 將 Player 從目前影格 seek 到目標影格。
- 站點路線進度按投影後每段距離累積，抵達目標影格時列車標記精確落在該站點。

## 無障礙與安全

- 路線區提供繁中 `aria-label`，目前站點資訊使用 `aria-live="polite"`。
- 控制使用原生 `<button>`，第一站的上一站按鈕為 disabled。
- 不公開住宿或即時定位；畫面標示「城市級行程規劃」。
- 不使用 D3 transition、CSS keyframes、計時器或 GSAP 自動播放來驅動 composition。

## 驗收

- 每次有效滾輪操作恰好前進或後退一站。
- 第一站向上與完成後向下可正常離開路線區。
- 下一站文案、計數與目前站點同步。
- 跳過路線可到達 `#latest`。
- Remotion Player 無播放鍵與控制列。
- `npm run lint`、導航單元測試與 `npm run build:github` 成功。
